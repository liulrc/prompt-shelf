# 词匣 1.4 产品审视与界面改版

词匣服务于两种不同长度的任务。写提示词时，需要看清原文、修改和可复用的片段。找一条刚复制的内容时，只需要选中它，回到原来的应用粘贴。工作台和全局弹窗分别为这两种任务保留空间。

以下判断来自对 1.3 工作流、窗口尺寸、设置与历史数据结构的审视，以及对公开产品界面的比较。优先级属于设计判断，未进行用户行为统计。

## 已落实的改动

| 原来的使用成本 | 1.4 的处理 | 可复核的操作 |
| --- | --- | --- |
| 在 100 条附加模板间挑选时，卡片摘要容纳的原文有限，容易反复进出编辑器 | 工作台将列表和使用预览并列。选定模板能直接使用，也可进入编辑器改写。我的模板与附加库分别管理 | 按分类或关键词找到一条模板，查看实际复制文字，再打开使用历史核对 |
| 同一页面中的导航、示例、改写与主操作争夺注意力 | 桌面主操作使用深青色。正文以独立的示例色和改写色标明可变内容与本次编辑，删除内容仍可在对照中查看。深浅配色跟随系统 | 改写一个示例，再拖入另一条模板，对比原文、修改和复制结果 |
| 设置要穿过模型表单才能看到后台控制与快捷键 | 通用、AI 模型、软件更新成为三个固定位置。切换分页保留表单内容，模型接口仅在查看对应分页时加载 | 用方向键切换设置页，再从 AI 优化页直接进入模型配置 |
| 旧版升级依赖找下载页、选择平台、退出和替换程序 | 设置展示已安装版本、更新说明、下载与校验状态。手动安装与自愿开启的空闲自动安装共用原生更新流程 | 检查当前版，断网后重试，有新版时更新，保留编辑中的工作 |
| 剪贴板和截图工具由多个独立窗口组成，选择、预览和导出的主次容易混淆 | 桌面历史栏以搜索和选取为主，截图库以多选置顶为主，编辑窗以画布和标注工具为主 | 用快捷键寻找文本或图片，回到原窗口粘贴；再从图库选择两张图片独立置顶 |

## 下一轮建议

| 优先级 | 使用场景 | 建议及验收方式 |
| --- | --- | --- |
| 优先 | Mac 更新后的开发者验证、屏幕录制授权，以及 Windows 的发布者提示影响对更新的信任 | 正式分发接入固定 Apple Developer ID、公证及 Windows 代码签名，用全新账户验证首次打开，再用旧账户验证升级及权限连续性。 |
| 优先 | 个人模板逐渐成为长期资产，换机或误操作后需要找回 | 提供「导出我的模板」和预览式导入。导入前显示新增、重复、冲突数量；由用户逐项决定冲突处理，往返导入应保留正文、分类和示例符号。 |
| 优先 | 跨应用复制可能包含短期验证码、客户资料。用户需要决定哪些内容值得长期留存 | 增加剪贴板保留天数和按来源排除。清理前给出受影响的数量，验证被排除来源的文本和媒体均未写入磁盘。 |
| 随后 | 想回到自己最常用的几条模板 | 在「我的模板」中增加手动置顶及最近使用排序。排序不改变模板收录归属，可用键盘找到并使用第一条置顶内容。 |

## 参考作品与取舍

- Raycast 的片段搜索把搜索、筛选和使用放在一处。词匣将这个思路用于附加库和个人库，并让模板的完整使用预览占据主要阅读区。[Raycast Snippets](https://manual.raycast.com/snippets)
- Raycast 的剪贴板历史围绕搜索与恢复工作上下文组织。词匣的快捷历史栏保留搜索焦点、方向键选择、回车复制及返回原窗口的流程。[Raycast Clipboard History](https://manual.raycast.com/clipboard-history)
- CleanShot X 将截图后的快速操作、标注和悬浮参考图分开。词匣对应保留框选后的直接动作、独立编辑窗与可多选的置顶图库，让每个窗口只有一件主要工作。[CleanShot X 功能概览](https://cleanshot.com/features)
- Apple 的设置指南强调位置稳定和清晰分组。设置采用三个固定分页，窄窗口仍保留页签，后台任务、更新反馈和失败原因留在各自的操作附近。[Apple Settings](https://developer.apple.com/design/human-interface-guidelines/settings)

## 核验边界

在浏览器和 macOS 上分别检查了界面状态和原生行为。浏览器回归覆盖模板搜索、直接使用与历史、拖入拼接、AI 模型配置、设置分页键盘导航、更新失败重试和进度。macOS 更新回归使用隔离的应用副本检查安装包、来源标记、替换与失败恢复。

Windows 安装包在 macOS 上交叉构建，验证范围包括版本比较、更新目录格式、安装文件及资源。Windows 系统实际执行安装、更新回滚和重启的验收脚本位于 tests/windows，本次交付没有在 Windows 上运行这组脚本。
