# 浏览器原型

在浏览器中打开项目根目录的 [index.html](../index.html) 即可体验。HTML 与 `prototype` 文件夹需要放在一起，无需安装依赖、配置密钥或联网。

- 在「附加库」按用途找模板。每个模板可自由改写，外部资料的参考链接在编辑器内。
- 直接编辑模板原文。改写 `【例：示例】` 中的内容即可替换变量，括号外的文字、标点和换行也可自由修改。
- 打开已有模板后，绿色高亮显示相对打开时原文新增或改写的字。展开「查看原文对照」，即可看到带红色删除线的旧字。改回原文，对应标记随即消失。新建空白模板时仅显示变量颜色。
- 「使用」复制去掉变量标记的实际文字。「保存」保留当前正文与变量标记，写入个人库。下次打开已保存的模板时，以该版本为新的比较基线。「取消」丢弃本次改动。
- 「我的模板」仅存个人条目。「使用历史」保留最近 100 次成功复制的全文。

## 剪贴板与截图

[打开剪贴板](../index.html#clipboard) · [打开截图工具](../index.html#capture) · [查看快速历史栏](快速历史栏预览.png)

- 打开剪贴板管理页，可主动读取、粘贴或拖入内容，也可选择本机图片或视频。按类型查找记录，预览图片或播放浏览器支持的视频。
- 在词匣页面聚焦时按 **Alt+Shift+V**（Mac 为 **⌥⇧V**）打开快速历史栏。输入关键词，按上下键选择，回车或单击复制，Esc 关闭。文本、图片及视频能否写入系统剪贴板取决于浏览器支持和授权。视频另可下载原文件。
- 在截图工具中可用示例试截、导入图片，或在支持的浏览器中授权捕获屏幕。长图可从滚动示例生成，也可手动滚动并逐屏拼接。截图原图进入历史，标注完成后可另存一条记录。图片可钉在页面内查看，并可导出整图或分页图片。

原型把剪贴板记录存入浏览器的 IndexedDB，可单条移除，最多保留 100 条且总计不超过 64 MiB（含缩略图），达到上限时优先保留新记录。三条演示内容单独提供。浏览器存储不可用时，当前会话中的记录可供临时体验。支持目录选择的浏览器可经授权导出到指定目录，其他浏览器使用文件下载。

浏览器原型保留作交互审阅。初版设计、归档策略与验收目标见[产品方案](产品方案.md)。
