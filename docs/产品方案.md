# 词匣 · Prompt Shelf

**提示词、剪贴板与截图工具｜交互原型与桌面版方案**

[打开交互原型](../index.html) · [查看编辑器截图](编辑器预览.png)

词匣可以保存常用 AI 指令、找回刚复制的文本或媒体，也可以截取并标注屏幕内容。本轮用网页原型审阅这些操作。最终以独立的 macOS 和 Windows 安装包交付。

## 从一次真实使用开始

假设你今天要学习一个开源项目，明天要部署另一个项目。附加库里只需要保存一条模板。

```text
详细阅读并【例：学习/部署】【例：GitHub】上的【例：https://github.com/Vincentwei1021/video-shotcraft】项目。
```

直接在原文中把 `【例：学习/部署】` 改成 `【例：部署】`，把网址换成自己的项目，再把开头的「详细阅读」改成「阅读」。「使用」会复制下列纯文本，直接粘贴就能发给 AI。

```text
阅读并部署GitHub上的https://github.com/example/my-project项目。
```

如果需要 AI 先列出项目结构，在正文末尾加一句「先列出项目结构。」这句新文字会在编辑区高亮，刚刚删掉的「详细」仍可在只读改动记录里核对。如果此后每次都需要这句话，点「保存」，给个人副本起名。下次打开副本时，这句话已经是原文的一部分，动作、平台和网址仍可改写。

## 提示词入口

| 入口 | 何时打开 | 存放什么 |
| --- | --- | --- |
| 附加库 | 想找一个可直接套用的写法 | 按视频、文案、研究、开发、办公等用途陈列模板。条目说明适用场景，并提供可核对的来源或标明用户示例。 |
| 我的模板 | 已有自己的固定工作习惯 | 个人从空白新建的模板、从附加库改写的副本。即使同名，两边也各有独立记录。 |
| 使用历史 | 想拿回上次实际复制的那段话 | 按时间倒序保留最近 100 次成功复制的全文、模板名和时间。以后再改模板，仍能找回当时的版本。 |

附加库按能否直接完成常见任务选材。例如视频模板可以给出口播对应的镜头清单，文案模板可以指定读者、语气和交稿格式。资料来源用于核对方法，中文模板由本项目重新编写。用户给出的「把题目问深」也收入库中，保留专家补充、原始素材、具体方法和独立验证四个追问。

## 编辑器

打开模板后直接在原文中编辑，可同时改写括号里的示例、固定句式、标点和换行。成对的 `【】` 标出可变部分，变量有专门的字体颜色。使用预览展示最终写入剪贴板的纯文本。

新写模板时推荐 `【例：示例】`，也可简写成 `【示例】`。短中文备选词如 `【例：学习/部署】` 默认取第一项。要执行其他动作，直接改写括号中的内容。网址内的斜杠按原文保留。

编辑已有模板时，以打开时的原文为比较基线。编辑区用绿色高亮新增和替换后的文字。展开「查看原文对照」，红色删除线标出删去的文字，包括被替换的旧字。把文字改回原样，对应标记随即消失。新建空白模板时仅保留变量颜色，保存并重新打开后才有可对照的原文。

| 按钮 | 这次动作 | 再次打开时 |
| --- | --- | --- |
| 取消 | 退出编辑，丢弃本次草稿。 | 模板仍为打开前的内容。 |
| 使用 | 将当前正文的变量展开成纯文本，写入系统剪贴板。写入成功才追加历史。 | 再打开原模板时仍以原来的正文为基线。历史保留本次复制的实际文字。 |
| 保存 | 连同括号变量保存当前正文。新模板、附加库草稿均写入「我的模板」。编辑个人模板时可选「替换当前」或「另存为新模板」。 | 再打开保存的条目时，以刚保存的版本为基线，改动记录从空白开始。单纯保存不会计入使用历史。 |

## 原型审阅路径

1. 从附加库打开项目模板。直接改写括号里的动作和链接，删去「详细」，再在末尾补一句要求。观察编辑区高亮和只读改动记录，把一句话改回原样，看对应差异消失。
2. 点「使用」，粘贴到任意文本编辑器，核对变量、标点和换行。在使用历史核对这次的全文，再打开附加库中的同一条，核对原文。
3. 重新修改并保存一份个人模板。打开已保存的副本，核对变量括号与最新正文，确认初始没有改动。再次编辑，分别测试替换当前和另存两种保存方式。
4. 新建一条带 `【例：产品经理】` 的模板，写一段多行正文并保存。再次打开，修改后点「取消」。在同一浏览器、同一路径重开原型，检查个人模板和历史。

原型使用浏览器本地存储。审阅时请用同一浏览器打开同一入口。清理站点数据会一并清除该原型中的个人模板和历史。提示词的编辑、保存和使用均可离线完成，查看外部来源需联网。

## 剪贴板与截图怎样使用

[剪贴板页面](剪贴板预览.png) · [快速历史栏](快速历史栏预览.png) · [长截图标注页面](截图工具预览.png)

| 操作 | 浏览器原型中可以体验 | 正式桌面版 |
| --- | --- | --- |
| 收集与回用 | 在页面内主动读取、粘贴、拖入或选择文件。按类型查看文本、图片和视频，截图归在图片中。文本和媒体按浏览器允许的格式写入剪贴板，视频另可下载原文件。 | 开启系统剪贴板记录后，其他应用复制的受支持内容自动入库。文本回写为文本，截图可作为图片粘贴，视频优先回写为本地文件引用，供 Finder、资源管理器等支持粘贴文件的应用使用。 |
| 快速历史栏 | 页面聚焦时按 **Alt+Shift+V**，Mac 为 **⌥⇧V**。输入关键词，上下键选择，回车或单击复制，Esc 关闭。 | 从正在工作的应用直接唤起同一历史栏。选中后写入剪贴板，关闭面板并将焦点还给原窗口，用户可继续粘贴。快捷键被占用时可更换。 |
| 截图与长截图 | 试截示例、导入图片，或在浏览器授权后截取共享画面。通过滚动示例或手动逐屏采集拼成长图。原图进入历史，可画框、划线、改色、撤销，将标注版另存为一条。支持整图和分页导出。 | 使用系统接口截取屏幕或窗口，并裁取选区。对支持滚动的目标自动翻动，匹配相邻画面重叠区后拼接。内容跳动、重复或到底时停下，可接续手动采集。 |
| 钉图与归档 | 已钉图片可在词匣页面内移动、跨站内模块查看。经浏览器授权可导出到所选目录，也可下载到本机。 | 独立悬浮窗可将截图放在其他普通应用之上。图片、长图、标注图和视频文件自动归档到本地，保留原文件或原图以供复用。 |

提示词「使用历史」记录成功复制的指令。剪贴板历史还收录外部复制项及截图，复制自己的历史条目时应识别本次回写，避免重复归档。

## 轻量桌面版的技术选择

**优先采用 Rust 共享核心、两端薄原生适配和按需加载的主窗口。** Rust 负责查询索引、媒体归档、去重、配额和长图拼接。常驻时只运行监听与快捷键服务。快速历史栏和钉图窗口使用 macOS AppKit、Windows Win32，以缩略图和分页查询绘制当前可见记录。打开完整工作台时才创建系统 WebView，完全关闭主窗口时销毁其视图。视频播放器和截图流也随各自操作结束释放。

| 实现路线 | 何时采用 |
| --- | --- |
| Rust + 系统窗口 + 按需 WebView | 首选路线。两端共享数据与归档逻辑，已有 HTML 编辑器可复用。Tauri 2 可承担工作台和打包，须验证托盘常驻且主窗口已关闭时的实际进程占用。macOS 调用系统 WKWebView，Windows 使用 WebView2。[Tauri 架构](https://v2.tauri.app/concept/architecture/) · [系统 WebView](https://v2.tauri.app/reference/webview-versions/) |
| 两端完全原生 | 若发布版实测表明工作台开销超出目标，可用 Swift/AppKit 和 C++/Win32 分别实现完整界面，并保留共享核心。这一路线需维护两套编辑器、差异高亮、键盘导航和无障碍交互。[Apple AppKit](https://developer.apple.com/documentation/appkit) |
| JavaScript/TypeScript + Electron | 便于直接沿用网页交互，发行物随附 Chromium 和 Node.js。可作为同功能对照构建，以实际安装文件及进程内存决定取舍。[Electron 架构说明](https://www.electronjs.org/docs/latest/) |

### 系统接口与权限

- **macOS。** 以 `NSPasteboard.general.changeCount` 检查剪贴板变更，计数变化后再读取受支持的文本、图片或文件 URL。检测时间间隔内若发生多次覆盖，可能只能取得最后一项。按系统版本处理程序读取权限，用户拒绝或暂停时停读。截图走 ScreenCaptureKit，在用户发起时选择来源和申请所需屏幕录制权限。跨应用自动滚动若需辅助功能控制，仅在启用该功能时请求，可改用手动滚动。[变更计数](https://developer.apple.com/documentation/appkit/nspasteboard/changecount) · [剪贴板访问控制](https://developer.apple.com/documentation/appkit/nspasteboard) · [文件 URL](https://developer.apple.com/documentation/appkit/nspasteboard/pasteboardtype/fileurl) · [Apple 屏幕捕获](https://developer.apple.com/documentation/screencapturekit/capturing-screen-content-in-macos)
- **Windows。** 用 `AddClipboardFormatListener` 接收 `WM_CLIPBOARDUPDATE`。分别处理 Unicode 文本、位图及 `CF_HDROP` 文件列表，文件在写回前检查存在性和读取权限。目标应用暂时占用剪贴板时限次重试。Windows.Graphics.Capture 通过系统选择器取得捕获目标，支持自动化滚动的窗口可使用 UI Automation ScrollPattern。[变更通知](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-addclipboardformatlistener) · [剪贴板格式](https://learn.microsoft.com/en-us/windows/win32/dataxchg/standard-clipboard-formats) · [屏幕捕获](https://learn.microsoft.com/en-us/windows/apps/develop/media-authoring-processing/screen-capture) · [滚动接口](https://learn.microsoft.com/en-us/windows/win32/api/uiautomationclient/nf-uiautomationclient-iuiautomationscrollpattern-scroll)
- **面板与贴图。** 注册单个系统热键，菜单栏或托盘保留手动入口。置顶仅作用于用户钉住的图窗，退出钉图即释放。实机验收覆盖切换应用、全屏空间、跨显示器与不同缩放比例。[系统热键适配](https://v2.tauri.app/plugin/global-shortcut/) · [窗口置顶接口](https://v2.tauri.app/reference/javascript/api/namespacewindow/#setalwaysontop)

### 本地归档与隐私

个人库与索引放在应用数据目录的 SQLite 中。首次启用自动记录时说明记录类型和存放位置，可暂停记录、删单条或清空历史。对来源主动标记为敏感或禁止纳入历史的剪贴板项目跳过归档。内容和文件只在本机处理。[Windows 剪贴板历史控制](https://learn.microsoft.com/en-us/windows/win32/dataxchg/clipboard-formats#cloud-clipboard-and-clipboard-history-formats)

用户可选择图片和视频归档目录，默认使用应用本地数据目录。媒体文件写入受管理的子目录，数据库只存类型、时间、路径、字节数及校验信息。视频通过文件引用定位，流式复制到归档目录，保留扩展名。文件完整落盘后再提交数据库记录，空间不足时标明归档失败。给归档设置可调的保留天数、总容量和单文件上限，清理仅作用于词匣管理的副本。提示词「使用历史」继续单独保留最近 100 条。

### 桌面安装包与验收

| 阶段 | 实现选择 | 验收方式 |
| --- | --- | --- |
| 功能回归 | 用相同测试集在两个桌面系统运行。 | 从外部编辑器、浏览器、Finder 或资源管理器复制中文、截图和视频文件，验证自动入库、快捷键唤起和跨应用粘贴。检查原图与标注版、长图接缝和分页、钉图、暂停、拒绝权限、归档满额、重启及升级。 |
| 性能验证 | 每个平台在同一台测试机上，用相同素材比较各路线的发布构建，记下操作系统、处理器及 WebView 版本。 | 分别记录压缩安装包、安装后增量和额外运行时大小。测冷启动、热键到面板可用的延迟，以及后台空闲、工作台打开、长图拼接和视频归档时的 CPU、整组进程内存及峰值。重复测试并记录中位数、峰值和关闭窗口后的回落情况。 |
| macOS 安装包 | 在 macOS 上构建包含 `.app` 的 `.dmg`。面向站外公开分发时，使用发布方的 Developer ID 完成签名与公证。 | 在声明支持的芯片与系统上，下载安装包，拖入「应用程序」，首次启动并完成上述流程。[DMG 打包说明](https://v2.tauri.app/distribute/dmg/) · [macOS 签名与公证](https://v2.tauri.app/distribute/sign/macos/) |
| Windows 安装包 | 在 Windows 上构建 NSIS `-setup.exe`。常规包使用设备已有的 WebView2，缺少时引导安装。需要断网安装时另提供内含 WebView2 离线安装器的包，单列其体积。面向公开分发时，用发布方证书签名。 | 在干净的 Windows 环境离线安装并启动，验证中文输入、剪贴板、再次安装升级和卸载。[安装器与离线运行时](https://v2.tauri.app/distribute/windows-installer/) · [Windows 代码签名](https://v2.tauri.app/distribute/sign/windows/) |

两端安装包连同版本号、支持的系统与处理器、实际验收结果一并交付。安装包体积与常驻占用待双端发布构建实测。
