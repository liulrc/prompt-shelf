# 词匣 · Prompt Shelf

**桌面提示词工具｜首版审阅稿**

[打开交互原型](../index.html) · [查看编辑器截图](编辑器预览.png)

词匣让经常重复的一段指令只写一次。每次选中模板，改几个词、一个网址，或整段重写，点「使用」就能粘贴到常用的 AI 对话框。本轮交付可在本机体验的网页原型。产品最终以独立的 macOS 和 Windows 安装包交付。

## 从一次真实使用开始

假设你今天要学习一个开源项目，明天要部署另一个项目。附加库里只需要保存一条模板。

```text
详细阅读并【例：学习/部署】【例：GitHub】上的【例：https://github.com/Vincentwei1021/video-shotcraft】项目。
```

直接在原文中把 `【例：学习/部署】` 改成 `【例：部署】`，把网址换成自己的项目，再把开头的「详细阅读」改成「阅读」。「使用」会复制下列纯文本，直接粘贴就能发给 AI。

```text
阅读并部署GitHub上的https://github.com/example/my-project项目。
```

如果需要 AI 先列出项目结构，在正文末尾加一句「先列出项目结构。」这句新文字会在编辑区高亮，刚刚删掉的「详细」仍可在只读改动记录里核对。如果此后每次都需要这句话，点「保存」，给个人副本起名。下次打开副本时，这句话已经是原文的一部分，动作、平台和网址仍可改写。

## 三个入口

| 入口 | 何时打开 | 存放什么 |
| --- | --- | --- |
| 附加库 | 想找一个可直接套用的写法 | 按视频、文案、研究、开发、办公等用途陈列模板。条目说明适用场景，并提供可核对的来源或标明用户示例。 |
| 我的模板 | 已有自己的固定工作习惯 | 个人从空白新建的模板、从附加库改写的副本。即使同名，两边也各有独立记录。 |
| 使用历史 | 想拿回上次实际复制的那段话 | 按时间倒序保留最近 100 次成功复制的全文、模板名和时间。以后再改模板，仍能找回当时的版本。 |

附加库按能否直接完成常见任务选材。例如视频模板可以给出口播对应的镜头清单，文案模板可以指定读者、语气和交稿格式。资料来源用于核对方法，中文模板由本项目重新编写。用户给出的「把题目问深」也收入库中，保留专家补充、原始素材、具体方法和独立验证四个追问。

## 编辑器

打开模板后直接在原文中编辑，可同时改写括号里的示例、固定句式、标点和换行。成对的 `【】` 标出可变部分，变量有专门的字体颜色。使用预览展示最终写入剪贴板的纯文本。

新写模板时推荐 `【例：示例】`，也可简写成 `【示例】`。短中文备选词如 `【例：学习/部署】` 默认取第一项。要执行其他动作，直接改写括号中的内容。网址内的斜杠按原文保留。

编辑已有模板时，以打开时的原文为比较基线。编辑区用绿色高亮新增和替换后的文字。展开「查看原文对照」，红色删除线标出删去的文字，包括被替换的旧字。把文字改回原样，对应标记随即消失。新建空白模板时仅保留变量颜色，保存并重新打开后才有可对照的原文。

| 按钮 | 这次动作 | 再次打开时 |
| --- | --- | --- |
| 取消 | 退出编辑，丢弃本次草稿。 | 模板仍为打开前的内容。 |
| 使用 | 将当前正文的变量展开成纯文本，写入系统剪贴板。写入成功才追加历史。 | 再打开原模板时仍以原来的正文为基线。历史保留本次复制的实际文字。 |
| 保存 | 连同括号变量保存当前正文。新模板、附加库草稿均写入「我的模板」。编辑个人模板时可选「替换当前」或「另存为新模板」。 | 再打开保存的条目时，以刚保存的版本为基线，改动记录从空白开始。单纯保存不会计入使用历史。 |

## 原型审阅路径

1. 从附加库打开项目模板。直接改写括号里的动作和链接，删去「详细」，再在末尾补一句要求。观察编辑区高亮和只读改动记录，把一句话改回原样，看对应差异消失。
2. 点「使用」，粘贴到任意文本编辑器，核对变量、标点和换行。在使用历史核对这次的全文，再打开附加库中的同一条，核对原文。
3. 重新修改并保存一份个人模板。打开已保存的副本，核对变量括号与最新正文，确认初始没有改动。再次编辑，分别测试替换当前和另存两种保存方式。
4. 新建一条带 `【例：产品经理】` 的模板，写一段多行正文并保存。再次打开，修改后点「取消」。在同一浏览器、同一路径重开原型，检查个人模板和历史。

原型使用浏览器本地存储。审阅时请用同一浏览器打开同一入口。清理站点数据会一并清除该原型中的个人模板和历史。提示词的编辑、保存和使用均可离线完成，查看外部来源需联网。

## 审阅通过后的桌面交付

| 阶段 | 实现选择 | 验收方式 |
| --- | --- | --- |
| 原生桌面版 | 用 Tauri 2 承载审定的界面，通过原生接口写剪贴板。附加库作为只读资源随包分发，个人模板和历史写入应用数据目录下的 SQLite 数据库。 | 分别在 macOS 与 Windows 上粘贴到外部编辑器，核对中文、长链接、多行文本。重启应用并升级附加库，核对个人副本及历史仍可读。 |
| macOS 安装包 | 在 macOS 上构建包含 `.app` 的 `.dmg`。面向站外公开分发时，使用发布方的 Developer ID 完成签名与公证。 | 在声明支持的芯片与系统上，下载安装包，拖入「应用程序」，首次启动并完成上述流程。[DMG 打包说明](https://v2.tauri.app/distribute/dmg/) · [macOS 签名与公证](https://v2.tauri.app/distribute/sign/macos/) |
| Windows 安装包 | 在 Windows 上构建 NSIS `-setup.exe`。离线安装版内含 WebView2 离线安装器。面向公开分发时，用发布方证书签名。 | 在干净的 Windows 环境离线安装并启动，验证中文输入、剪贴板、再次安装升级和卸载。[安装器与离线运行时](https://v2.tauri.app/distribute/windows-installer/) · [Windows 代码签名](https://v2.tauri.app/distribute/sign/windows/) |

两端安装包连同版本号、支持的系统与处理器、实际验收结果一并交付。系统剪贴板只在用户主动使用时写入，个人模板和历史由本机保存。
