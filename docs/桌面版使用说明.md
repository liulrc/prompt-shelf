# 词匣桌面版 1.1.0

## 安装和首次使用

从 1.0.0 升级时，先从菜单栏或系统托盘选择「退出词匣」，再替换 Mac 应用或运行 Windows 安装程序。打开新版「设置」，标题旁会显示 **1.1.0**。新版沿用原来的数据目录和快捷键配置。

- **macOS 14 及以上**　打开 [DMG](../dist/PromptShelf-1.1.0-macOS-universal.dmg)，将「词匣」拖入「应用程序」后从那里启动。应用包含 Apple Silicon 和 Intel 两种架构。当前构建使用本机临时签名，尚未取得 Developer ID 签名与苹果公证。
- **Windows 10 1809 及以上或 Windows 11，x64**　运行 [Setup.exe](../dist/CiXia-1.1.0-Windows-x64-Setup.exe)，安装到当前用户。已有 WebView2 Evergreen Runtime 时可直接使用。设备缺少该组件时，安装器通过微软引导程序联网获取。词匣安装器尚无发布方签名。
- **macOS 截图授权**　首次截图时允许系统提示的屏幕录制权限。要让词匣替你滚动其他应用，还需在「系统设置 → 隐私与安全性 → 辅助功能」允许词匣。手动滚动模式只需截图权限。如果系统提示重新打开应用，先从菜单栏退出，再启动。

Mac 如提示无法验证开发者，可先核对本项目的安装包 SHA-256，再按苹果文档处理该应用的首次打开。Windows 离线设备可以预先安装微软提供的 x64 Evergreen 独立运行时，再运行词匣安装器。[Apple 首次打开说明](https://support.apple.com/zh-cn/102445) · [微软 WebView2 运行时下载](https://developer.microsoft.com/zh-cn/microsoft-edge/webview2/)

### Mac 升级后，录屏开关已开却仍提示需要权限

1.0.0 和 1.1.0 使用临时签名。macOS 的录屏开关可能仍关联旧版签名。升级到 1.1.0 时已在本机确认过这种情况。[Apple 对升级与签名身份的说明](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements/)

1. 保存正在编辑的内容，从菜单栏退出词匣。打开「系统设置 → 隐私与安全性 → 屏幕与系统录音」，选中旧的词匣，点 **−** 移除。
2. 点 **＋**，按 **⌘⇧G** 输入 `/Applications/词匣.app`，添加当前应用并打开录屏开关。按系统提示重新打开词匣。
3. 从词匣菜单栏选择「区域截图」验证。能框选并进入编辑窗即表示录屏授权已生效。辅助功能权限仅在要让词匣替你自动滚动时需要。

## 日常操作

| 全局快捷键 | 操作 |
| --- | --- |
| Option/Alt + A | 框选一个屏幕区域。松开鼠标后出现选区工具条。普通模式点「编辑截图」，需要截取网页的后续内容时切到「滚动长截图」。完成取图后原图自动归档并进入独立编辑窗。 |
| Option/Alt + Q | 打开独立卡片弹窗。键入关键词，按 ↑ ↓ 选中记录，按回车或单击卡片复制。弹窗关闭后，在原窗口按 ⌘V 或 Ctrl+V 粘贴。Esc 关闭。 |
| Option/Alt + Z | 打开近期截图库。点选一张或多张缩略图，再点「置顶」。每张图片有自己的浮窗，拖动窗口边角会等比缩放画面，关闭单张不会影响其他图片。 |
| Option/Alt + X | 打开「我的模板」。直接编辑原文，彩色示例标出可改内容，新增和改写处实时变色。「查看原文对照」可查看删掉的字。 |

在工作台或菜单栏、系统托盘打开「设置」即可更改四组快捷键。同一组合只能分配给一个操作。系统或其他程序占用的组合会显示冲突提示。关闭工作台后，菜单栏或托盘服务继续接收复制和快捷键；要彻底停止，可选择「退出词匣」。

「使用」把当前提示词复制到剪贴板并留下本次全文；「保存」将改写写入个人模板库；「取消」退出本次编辑。内置分类模板可另存到个人库。

## 滚动长截图与标注

1. 把网页或文档停在起点，按 **Option/Alt + A**，在同一显示器上框选可滚动的内容。默认是普通截图；点选区旁的「编辑截图」即可打开单独的标注窗。
2. 需要长图时，用同一工具条切到「滚动长截图」，把指针移到选区内，在原网页上连续向下滚动。词匣会自动采集和拼接，工具条显示已拼帧数和图像高度。也可使用「自动滚动」。
3. 看到底部或想要的段落后，点击工具条的完成按钮。只采到首屏时会停在现场提示；滚动距离过大、失去重叠时可往回滚一些再继续。尽量将固定导航、侧栏和动画留在选区外。
4. 普通和长截图都在单独窗口中打开。初始视图完整显示整张图，可切换到适应宽度或原尺寸检查细节。画框、直线、箭头，或选「文字标注」后点击图上位置输入中文、设置字号和颜色。
5. 「复制并完成」将当前画面写入系统剪贴板并关闭编辑窗；有标注的副本会加入历史。「另存为」可保存整图 PNG，长图还可分页导出 ZIP。「置顶」会将当前画面放进独立浮窗。取消编辑不改动已归档的原图。
6. 用 **Option/Alt + Z** 呼出近期截图库，选中多张后一次置顶。重新选中已置顶的历史图片会将已有的浮窗带到前面。升级后，原有快捷键自定义配置继续生效。

## 本地历史

「设置 → 跨应用自动记录」控制来自外部应用的复制。关闭后仍可主动使用模板、添加记录和截图。文本、图片及视频文件均可按关键词检索。图片和视频记录显示系统能解码的缩略图。对于视频文件，在支持文件粘贴的目标应用中粘贴即可。

两端保留最近 100 条剪贴板记录，文本与托管媒体内容共用 64 MiB 预算；超过预算从最旧条目开始移除。缩略图、数据库或索引、系统 WebView 缓存另占空间。复制超过该预算的媒体文件时保留文件引用，移动或删除原文件会影响预览与再次粘贴。提示词的「使用历史」单独保留最近 100 次。

macOS 数据位于 `~/Library/Application Support/词匣`，Windows 数据位于 `%LOCALAPPDATA%\CiXia\Data`。工作台通过系统 WebView 显示，剪贴板监听、快捷键、钉图和截图由本机服务处理。

## 版本验证

1.1.0 的截图回归使用滚动中文网页，在首尾设置可检测的色块，以图像尺寸和实际像素验证后续页面已拼入。在已授权屏幕录制及辅助功能的 Mac 上，可运行 `tests/mac/test-web-capture.sh wk` 验证 WebKit，或用 `tests/mac/test-web-capture.sh chrome` 验证独立的临时 Chrome 窗口。设置 `PS_CAPTURE_TEST_STICKY=1` 可再覆盖固定页头。

- Apple Silicon Mac 从挂载的 DMG 复制出应用后运行。验证独立编辑窗完整显示长图、中文标注写入剪贴板 PNG、两张截图同时置顶、关闭一张保留另一张、窗口变大时钉图实际像素范围随之扩大。Intel 版本已编入同一包。
- Chrome 固定页头网页的 Retina 选区为 1248 × 668 像素。手动滚动得到 1248 × 2212 像素，自动滚动得到 1248 × 2213 像素。两张图均保留页尾，固定标题只出现一次。[查看实测长图原件](Chrome网页长截图实测.png)
- WebKit 在 1140 × 552 像素选区上，手动与自动滚动均生成了 1140 × 2202 像素的长图。原生快捷键测试从另一前台应用呼出图库，再按 Esc，焦点回到原窗口。
- Windows x64 版本在本机交叉构建。已解包校验主程序、WebView2 Loader 与 31 个界面资源。当前环境没有 Windows 真机或虚拟机，系统级点击、滚动、置顶交互尚未在 Windows 上实测。

安装包 SHA-256 可用于核对文件完整性。[校验清单](../dist/SHA256SUMS.txt)

## 构建

两端共用无第三方依赖的 Rust 图像重叠检测代码。macOS 使用 Swift、AppKit、ScreenCaptureKit 和系统 SQLite；Windows 使用 C++、Win32 和按需创建的 WebView2，剪贴板索引独立写入本地 JSON。本版将归档放在两端各自的原生服务中。生产安装包位于 `dist/`。

- macOS 构建需要 Xcode 命令行工具与 Rust 的 `aarch64-apple-darwin`、`x86_64-apple-darwin` 目标。在项目根目录运行 `desktop/scripts/build-macos.sh`。
- Windows x64 可在 macOS 或 Linux 交叉构建。安装 mingw-w64、NSIS、Python 3、curl、unzip 和 Rust 的 `x86_64-pc-windows-gnu` 目标，运行 `desktop/windows/build.sh`。脚本固定 SDK 和 JSON 库版本，并将第三方许可证放入安装包。
